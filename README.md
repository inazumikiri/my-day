# мой день — как поставить на айфон

Приложение полностью офлайновое: все данные лежат только в твоём телефоне, никуда не отправляются.
Интернет нужен ровно один раз — чтобы телефон скачал файлы. Дальше работает без сети, в самолёте, где угодно.

## что в комплекте

| файл | зачем |
|---|---|
| `index.html` | само приложение |
| `sw.js` | service worker — он и делает офлайн |
| `manifest.json` | имя, цвет, иконки для «на экран Домой» |
| `icon-180.png`, `icon-192.png`, `icon-512.png` | иконки |

Все файлы должны лежать **в одной папке**, рядом друг с другом.

## 1. заливаем на github

1. github.com → **New repository**. Имя любое, например `my-day`. Public. **Create**.
2. На странице репозитория → **Add file → Upload files** → перетащить все 6 файлов → **Commit changes**.
3. **Settings** (вкладка сверху) → слева **Pages**.
4. Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
5. Подождать 1–2 минуты, обновить страницу. Появится адрес вида
   `https://твой-логин.github.io/my-day/`

Репозиторий обязательно **public** — на бесплатном тарифе Pages иначе не включится.

## 2. ставим на экран «Домой»

1. Открыть этот адрес **в Safari** (не в хроме — на айфоне ярлык умеет делать только Safari).
2. Дать странице полностью загрузиться, подождать секунд пять — в это время сохраняется офлайн-копия.
3. Кнопка «Поделиться» (квадрат со стрелкой) → **На экран «Домой»** → **Добавить**.

Теперь на рабочем столе иконка, запускается на весь экран, без адресной строки. Можно включить авиарежим и проверить — всё работает.

## 3. важное про данные

Данные живут в памяти браузера этого конкретного приложения. Отсюда три правила:

- **Данные не переезжают сами.** То, что ты накопила в файле на компьютере или в Safari, в приложении с экрана «Домой» не появится. Перед переездом: открыть старую версию → ⚙ (справа от вкладок) → **скачать копию**, потом в новом приложении → ⚙ → **загрузить копию**.
- **Делай копию раз в месяц.** iOS иногда чистит данные сайтов, которыми давно не пользовались, а ещё копия спасает при смене телефона. Файл можно кинуть в «Файлы» или отправить себе в телеграм.
- **Не удаляй иконку с рабочего стола** «чтобы переустановить» — вместе с ней удаляются и данные. Сначала копия, потом всё остальное.

## 4. уведомления

Работают **только** если приложение запущено с экрана «Домой» (в обычном Safari айфон их не даёт).

1. Открыть приложение с иконки → **⚙** справа от вкладок.
2. Раздел «уведомления» → **включить** → в системном окошке **Разрешить**.
3. Кнопка **проверить** — если баннер пришёл, всё настроено.
4. Дальше у каждого события (вкладка «неделя» → тап по событию) выбрать «уведомление»: за 15 минут, за час и так далее.

Честно про ограничение: напоминания ставятся, когда приложение открыто, и живут, пока айфон держит его в памяти. Свернула на пару часов, система выгрузила — таймеры умерли, баннер не придёт. Поэтому:

- для важного (пары, врач, поезд) лучше дублировать в стандартный «Календарь» или «Напоминания» — они умеют будить телефон;
- приложение полезно открывать утром: при запуске оно заново расставляет напоминания на весь оставшийся день.

Если случайно нажала «Не разрешать», кнопка больше не появится — включается в **Настройки айфона → Уведомления → мой день**.

## 5. если что-то поменяешь в приложении

Загрузила новый `index.html` в репозиторий, а на телефоне старая версия? Так и должно быть первые пару запусков — service worker отдаёт сохранённую копию. Чтобы обновление приехало сразу:

1. В `sw.js` поменяй строчку `const CACHE = 'myday-v1';` на `'myday-v2'` (дальше v3, v4 и так далее).
2. Залей оба файла.
3. На телефоне открой приложение при живом интернете и закрой-открой ещё раз.

## 6. если офлайн не заработал

- Проверь, что адрес начинается с `https://` — service worker на http и на локальном файле не запускается.
- Проверь, что `sw.js` лежит там же, где `index.html`, и открывается по прямой ссылке `https://…/my-day/sw.js`.
- Первый заход должен быть с интернетом и до конца — если закрыть страницу через секунду, закэшироваться не успеет.
